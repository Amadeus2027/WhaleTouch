# 最小验证记录

环境：Linux 开发容器，无 DualSense，无用户 DeepSeek API Key。

已完成：

- 4 项 Core 测试：USB 格式与坐标、竖向头脚和分区边界、触摸结束与反馈归零、SSE 跨片段及余额解析。
- TypeScript 检查和前端生产构建。
- Chromium 浏览器首页启动，无页面运行错误，角色图片正常显示。

发布前补充一次窗口／动作最小检查及 Windows 构建结果。不将浏览器预览当成 Windows 启动或 HID 真机通过。

- 配置用户自己的 key 后，一次短聊天与取消、一次余额查询。
- 互动、静态休眠、隐藏三个状态的整个进程树 CPU／内存／GPU 简短抽样。
