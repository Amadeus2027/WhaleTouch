# 开发约束

- 目标是 Windows 原生桌宠，浏览器只用于 UI 和鼠标预览。
- 不开启触摸模式，不能调用 HID 枚举、打开、读取或输出。启动、显示、API 查询不接管手柄。
- 关闭触摸必须等待读取线程退出，停止马达并关闭设备；不使用虚拟驱动或独占设备锁，不自动重连。
- 原始 X 长轴从左至右映射头至脚，原始 Y 短轴映射身体左右。成女分区沿用上游，Q 版按大头比例调整。
- 真实传感器不提供手指压力。不存在的模型参数不可强写；缺失绑定用已有表情／姿态反馈。
- 所有反馈通过同一 HID 写入线程调度。上游灯条状态无法完整读取，释放时停止震动并发送灯条重置，不能承诺恢复任意第三方软件的原 RGB。
- 手动隐藏不被触摸或提醒擅自取消，重新显示不自动打开手柄。静态休眠与手动隐藏语义分开。
- API key 只通过后端 DPAPI 存取，不将 key 返回 UI，不记录请求头。固定官方 HTTPS 地址，不自动重试计费请求。
- 余额是账户快照，本应用 usage 是局部统计；不硬编码未知价格或推导全账户账单。
- 只在截止时间唤醒原生计时器；前端倒计时仅在面板显示时更新。
- 测试仅覆盖协议、映射、状态、反馈停止、流式解析与必要计时逻辑。只运行相关检查，不复制实现来写断言。
- 不批量哈希、不逐帧比像素、不建立截图回归、不跑长压测、不无故重复全量检查。
- 修改后以实际验证结果为准，Windows 打包、启动、手柄真机、官方 API 和性能数据分别报告。
